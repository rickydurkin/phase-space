# Learnings

One line per surprise. These feed the next programme version (MASTER 16.2).

- 15/10/2026: V8 on Apple Silicon fuses multiply-add in its fdlibm-derived Math functions, so a pure-JavaScript port of the same algorithms differs from Math.sin and friends by 1 to 2 ulp on about 1% of inputs. That is the cross-platform variation dmath removes, and a reminder never to use Math.* as a reference.
- 15/10/2026: decimal.js built from a double's shortest round-trip string is not an exact reference: subnormals have few significant digits and x near 1 raised to a huge power amplifies the string's rounding by the exponent. Build references from the double's bits (tests/helpers/dmath-ref.ts, exact()).
- 15/10/2026: typescript-eslint's scope manager resolves lib globals such as Date and performance, so an ESLint rule that only inspects unresolved references misses them; check the global scope's variables too.
- 15/10/2026: Dawn's native module (webgpu 0.6.2) segfaults inside Vitest's forked worker but runs cleanly under plain Node and node:test (ADR 0003).
- 15/10/2026: Rapier JavaScript handles are doubles whose bit pattern encodes the arena index and generation (the second body's handle prints as 5e-324). Never do arithmetic on them; store them as raw f64 bits in snapshots.
- 15/10/2026: npm 11.19 no longer runs install scripts by default; the webgpu package's postinstall (quarantine attribute removal on macOS) did not run and was not needed.
- 15/10/2026: bitECS 0.4 cannot restore an entity under a chosen id without its remapping serialiser, which conflicts with stable ids (ADR 0002).
- 15/10/2026: SwiftShader WebGPU on macOS 27 loses the device at the first canvas present in both the Chromium headless shell and full Chromium; the research's SwiftShader verification was on Linux, so CI and local runs need different Chromium modes (ADR 0009).
- 15/10/2026: Playwright's `reuseExistingServer` happily reuses a stale preview server left behind by a diagnostic script, so a rebuilt bundle was never served; kill listeners on the preview port before trusting an e2e run.
- 15/10/2026: the browser's automatic favicon request turned into a console error (404) that the zero-console-errors rule caught on the first e2e run; declare an empty icon in every page.
- 15/10/2026: decimal.js cannot be trusted as a reference for sin, cos and tan at large arguments unless the input is exact and the working precision covers the integer part; bc at 120 digits settled the disagreement in fdlibm's favour.
- 15/10/2026: Playwright's Firefox Nightly build does not start on this macOS even outside the tool sandbox and with Firefox's own sandboxes disabled; cross-engine checks for SpiderMonkey wait for CI.
- 15/10/2026: a Vite config built from `new URL(...).pathname` percent-encodes the space in "Application Support" and the build silently targets a path that does not exist; use fileURLToPath.
- 16/10/2026: the first full gate run caught four things no single suite had: an empty CI variable passed by the gate re-enabled the Firefox project; a deliberate GPU-process crash leaves an unhandled rejection from three.js's popErrorScope (D-001); fast-check found a heavy bouncy ball rolling off the fuzz floor's edge, which the "nothing below the floor" invariant wrongly counted as tunnelling; and the replay page bundled Rapier a second time (1.59 MB gzip), doubling the bundle. Run the whole gate early, not just the suites.
- 20/10/2026: a Stop-hook run of verify:fast failed when another project's headless-Chrome screenshot job drove the load average to 56 on 16 cores: the dmath fast-sample acos test timed out at 60 s (2.3 s alone with the same inputs) and the run took 177 s. Rerun under normal load: 24.9 s, all green. A red verify:fast with a timeout and a blown budget means check `uptime` before suspecting the code.
